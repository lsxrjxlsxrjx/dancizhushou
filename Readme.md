# 背鸡毛单词——完整使用说明

这是一个无需安装、打开 `index.html` 即可使用的单文件英语词汇学习工具。程序支持多词库管理、规划词库、AI 释义、单词查询、艾宾浩斯复习、拼写测验、段落解析、写作批改、本地实时保存以及 GitHub 云端同步。

> 数据默认保存在当前浏览器的本地存储中。建议同时配置 GitHub 云同步，并定期导出 JSON 备份。

## 快速开始

1. 下载仓库中的 `index.html`。
2. 使用现代浏览器打开该文件，推荐 Chrome、Edge 或其他 Chromium 浏览器。
3. 点击右上角 **⚙ 设置**，配置需要使用的 AI 接口。
4. 点击 **📚 管理词库** 创建或选择词库。
5. 点击 **＋ 查询/导入** 添加单词。
6. 等待后台 AI 释义任务完成后，进入 **🧠 背单词** 选择单词并开始测验。

程序没有构建步骤，也不需要安装 Node.js。你也可以把 `index.html` 放在静态网站、个人服务器或 GitHub Pages 上使用。

## 界面与核心概念

页面顶部包含以下主要入口：

| 入口 | 用途 |
| --- | --- |
| 词库下拉框 | 切换当前词库 |
| 📚 管理词库 | 新建、重命名、删除和配置普通/规划词库 |
| ＋ 查询/导入 | 查询单词、导入单词、解析段落、批改写作 |
| ☁️ 云同步 | 查看同步状态、手动上传或下载 |
| 🧠 背单词 | 进入背诵选择模式并开始拼写测验 |
| ⚙ 设置 | 配置 API、显示、背诵、云同步、队列和备忘录 |

### 当前词库

主列表、搜索、筛选、背诵和测验始终只读取当前词库。切换词库不会删除其他词库的数据。

### 单词注释

每个已完成 AI 生成的词条可以包含：

- 音标；
- 词性；
- 中文释义；
- 常见短语；
- 词形变化；
- 例句与翻译；
- 助记方法；
- 用户笔记、星级、错题次数和复习进度。

点击普通模式中的单词卡片可以展开或收起完整注释。

## 配置 AI 接口

进入 **⚙ 设置 → 通用**。程序将 AI 功能拆分为三组接口，三组可以使用同一家服务，也可以分别使用不同模型。

### 1. 导入 API（非流式）

用于导入单词、规划词库添加今日词汇、重新生成释义和重试失败词条。

需要填写 API 地址、API 密钥、模型 ID 和返回 JSON 的 Prompt。点击 **🧪 测试导入 API** 检查连接。

默认 Prompt 要求模型返回纯 JSON。请保留以下字段名：

```json
{
  "word": "规范后的单词",
  "phonetic": "音标",
  "pos": "词性",
  "meaning": "中文释义",
  "phrases": "常见短语",
  "inflections": "词形变化",
  "examples": "例句",
  "mnemonics": "助记"
}
```

`word` 字段用于让 AI 把普通名词规则复数 `s/es/ies` 还原为单数。程序只接受原词与 AI 返回词确实符合这些拼写关系的结果；不规则复数和短语不会由本地规则强制修改。

### 2. 查询单词 API（流式）

用于 **在线查询**，结果实时显示但不会写入词库。可以开启“查询完成自动发音”。点击 **🧪 测试查询 API** 检查连接。

### 3. 解析 API（流式）

用于英文段落逐句解析、针对原句继续追问以及六级写作和翻译批改。可以分别修改段落解析、追问和写作/翻译批改 Prompt。点击 **🧪 测试解析 API** 检查连接。

### 接口兼容要求

程序支持常见的 OpenAI 兼容接口：

- Chat Completions 风格接口；
- URL 中包含 `/responses` 的 Responses 风格接口；
- 查询和解析接口需要支持 SSE 流式返回；
- 服务端必须允许浏览器跨域请求。

如果测试失败，请先核对 API 地址、密钥、模型 ID、账户额度和浏览器跨域限制。

## 管理词库

点击顶部 **📚 管理词库**。程序包含普通词库和规划词库两种类型。

### 普通词库

适合随时查询和积累单词。

1. 输入新词库名称。
2. 点击 **＋ 普通词库**。
3. 在右侧将其设为当前词库。
4. 通过 **查询/导入** 添加词汇。

普通词库支持重命名、切换和删除。默认词库、笔记词库等内置词库会受到额外保护。

### 规划词库

适合雅思、托福、四六级等包含数千个原始词汇的长期学习计划。

#### 创建和设置

1. 输入名称，例如“雅思核心词汇”。
2. 点击 **＋ 规划词库**。
3. 设置“每日默认添加数量”，范围为 1–500。
4. 设置取词顺序：
   - **按导入顺序**：按照原始词表顺序取词；
   - **随机抽取**：从尚未加入学习列表的原始词中随机选择，不重复抽取。

#### 批量导入原始词

在“导入待学习单词”中粘贴词表，每行作为一个完整单词或短语；同一行也可以使用中英文逗号或分号分隔多个词条。词条内部的空格会保留，例如 `account for` 不会被拆开。原始词导入时只保存词表并自动去重，不调用 AI，因此可以一次导入数千个词条。

#### 查看和导出原始词

规划词库会显示原始词总数、已加入学习列表的数量、剩余待学习数量，以及每个原始词的具体内容与状态。原始词清单支持搜索、分页浏览（每页 100 个）以及 **导出原始词汇 TXT**。

#### 添加今日词汇

1. 输入本次添加数量。
2. 点击 **添加并生成 AI 释义**。
3. 程序从原始词表中取出对应数量，加入当前规划词库。
4. 释义生成复用普通导入的 AI 队列。

删除规划词库中的学习词条后，对应原始词会重新回到待学习状态，后续可以再次添加。原始词清单保留最初导入的拼写；如果 AI 将规则复数规范为单数，只修改实际学习词条，不改写原始词清单。

## 查询和导入单词

点击 **＋ 查询/导入 → 词汇查询/导入**。

### 输入格式

普通查询和导入要求每行一个单词或短语，例如：

```text
abandon
significant
take into account
```

### 在线查询

点击 **🔍 在线查询**：

- 使用查询 API；
- 流式显示结果；
- 不保存到词库；
- 同一查询面板中重复的单词会被跳过。

### 导入

点击 **📥 导入（后台处理）**：

- 单词立即加入当前词库；
- AI 注释任务进入后台队列；
- 可以关闭导入窗口继续操作；
- 同一批次自动忽略大小写相同的重复词；
- 词库中已经存在的词不会重复建立词条，而会更新其日期。

生成失败的词条会显示“失败”，可在词条上重排队，也可以在设置中批量重试。

## 浏览与管理单词

### 排序、搜索和显示

主界面支持：

- 按日期、字母或星级排序，并设置二级排序；
- 搜索当前词库；
- 按日期折叠词条；
- 展开某一天或全部单词的注释；
- 在“英文”“释义”“英+中”三种标题显示模式之间切换。

### 高级筛选

点击 **🎯 筛选**，可以组合今日待背、错题本、无周期、星级范围和复习周期 L0–L7。特殊状态之间取并集，星级和周期范围作为约束条件。

### 单词操作

每个词条支持英式/美式发音、设置 0–5 星、编辑单词和注释、添加笔记、重新生成 AI 注释以及删除词条。

### 批量操作

点击 **☑ 选择** 后可以：

- 单个选择；
- Shift 连选；
- 使用“区间连选”依次指定起点和终点；
- 按日期整组选择；
- 全选当前筛选结果；
- 批量设置星级、重新生成或删除。

“全选当前”只选择当前搜索和筛选后可见的单词。

## 背诵、测验与复习周期

### 开始测验

1. 切换到需要学习的词库。
2. 点击 **🧠 背单词**。
3. 使用搜索、筛选、日期、星级或周期筛出目标词。
4. 选择一个或多个已成功生成注释的词条。
5. 点击 **▶️ 开始测验**。

测验只读取当前词库和已选择的词，不会混入其他词库。

### 艾宾浩斯周期

正确拼写后，单词进入下一等级；下一次复习时间从答题完成时刻开始精确计算：

| 等级 | 下次复习 |
| --- | --- |
| L0 | 新词/当前待背 |
| L1 | 1 天后 |
| L2 | 2 天后 |
| L3 | 4 天后 |
| L4 | 7 天后 |
| L5 | 15 天后 |
| L6 | 30 天后 |
| L7 | 已掌握，不再自动进入待背 |

列表可以显示“距待背时间”，程序会定期刷新倒计时。

### 拼错处理

拼错后会加入错题本，并按照设置执行以下一种惩罚：

- **停滞**：等级不变，24 小时后复习；
- **降级**：退回一级，24 小时后复习；
- **重置严苛**：回到 L0 并立即待背。

还可以设置拼错后强制重写、第一遍拼对后移出错题本、是否显示音标或释义、挖空提示比例、自动发音以及答题后显示哪些注释。

背词选择栏支持批量移出错题本、调整星级和强制修改周期。使用“周期全面重置”前请先备份数据。

## 段落解析、划词查询与追问

进入 **＋ 查询/导入 → 段落解析**：

1. 粘贴英文段落。
2. 点击 **开始逐句深度解析**。
3. 等待流式结果完成。

解析结果支持：

- 点击或双击英文单词进行快速查询；
- 使用鼠标拖拽或移动端长按选择短语；
- 在划词弹窗中直接查询；
- 把选中单词或短语加入指定笔记词库，并附加笔记；
- 点击解析结果中的“原句：”继续针对该句追问。

划词添加的默认目标词库可在 **设置 → 通用 → 其他设置** 中修改。

## 写作与翻译批改

进入 **＋ 查询/导入 → 写作批改**：

1. 选择作文或翻译类型；
2. 输入题目和自己的答案；
3. 点击 **开始六级标准批改**。

程序会根据默认 Prompt 输出评分、总体评价、逐句问题、推荐表达和提升建议。点击批改结果中的原句、我的表达、推荐表达或推荐译文，可以继续针对该部分追问。

## 本地保存、备份和恢复

### 浏览器本地实时保存

所有数据修改都会立即写入浏览器本地存储，包括单词、词库、AI 注释、星级、笔记、错题、复习时间、规划词库原始词表、设置、备忘录和云端待同步状态。

刷新页面或重新打开同一页面时，程序会优先恢复较新的本地缓存。

> 清理浏览器网站数据、使用无痕模式、换浏览器配置文件或移动本地 HTML 文件，都可能使原来的本地缓存不可见。请使用 JSON 和云端同步做备份。

### 导出和导入 JSON

在 **设置 → 通用** 中：

- **📤 导出 JSON**：导出全部词库、学习进度和安全设置；
- **📂 导入 JSON**：可以选择合并或替换；
- 合并时根据词条 ID、更新时间和复习更新时间处理重复数据；
- 可以选择是否导入普通设置。

导出的 JSON 和上传到 GitHub 的数据会清除 API 密钥及 GitHub Token，密钥只保留在当前浏览器本地。

### 另存本地网页

点击 **💾 另存本地网页** 或按 `Ctrl+S` / `Command+S`，可以把当前数据嵌入新的 HTML 文件。开启“另存为加时间戳”后，会生成带时间的备份文件名。

### 清空数据

“清空词库数据”只清空当前词库。此操作不可撤销，执行前建议先导出 JSON。

## GitHub 云端同步

程序通过 GitHub Repository Contents API 读写独立仓库中的 `vocab_data.json`。推荐创建单独的私有仓库，不要把个人词库和 Token 放入公开程序仓库。

### 第一步：创建私有数据仓库

1. 登录 GitHub，点击右上角 **＋ → New repository**。
2. 输入仓库名称，例如 `my-word`。
3. 选择 **Private**。
4. 勾选 **Add a README file** 初始化主分支。
5. 创建仓库。

### 第二步：创建 `vocab_data.json`

进入新仓库，点击 **Add file → Create new file**，文件名必须严格使用全小写 `vocab_data.json`。填入以下初始内容并提交：

```json
{
  "schemaVersion": 4,
  "revision": 0,
  "words": [],
  "libraries": [],
  "currentLibraryId": "default",
  "config": {},
  "lastSaveTime": ""
}
```

### 第三步：创建 Fine-grained Token

1. 打开 GitHub **Settings**。
2. 进入 **Developer settings → Personal access tokens → Fine-grained tokens**。
3. 点击 **Generate new token**，设置名称和有效期。
4. 在 **Repository access** 中选择 **Only select repositories**，只选择数据仓库。
5. 在 **Repository permissions** 中把 **Contents** 设置为 **Read and write**。
6. 生成并立即复制以 `github_pat_` 开头的 Token。

Token 只显示一次。建议使用最小权限并设置合理的过期时间。

### 第四步：在程序中配置

进入 **⚙ 设置 → 通用 → 云端同步设置**：

- **GitHub 仓库名**：填写 `用户名/仓库名`，例如 `lsxrjxlsxrjx/my-word`；
- **专属 Token**：粘贴 Fine-grained PAT；
- 开启 **数据修改后自动保存云端**；
- 开启 **启动或回到前台时自动获取云端更新**；
- 点击 **保存设置**。

全新设备首次保存仓库和 Token 后，如果本地没有词库数据，程序会自动下载云端内容。Token 只保存在当前浏览器，因此每台新设备仍需配置一次。如果本机已经有数据但没有同步记录，程序不会自动覆盖，而会提示手动确认下载或上传。

### 自动保存策略

开启自动云端保存后：

- 每次修改立即保存到本地；
- 停止修改 45 秒后自动上传；
- 持续修改时最长等待 2 分钟上传一次；
- 测验结束后立即上传；
- AI 后台任务全部完成后立即上传；
- 页面切换到后台时尝试上传；
- 离线期间保留待上传状态；
- 网络恢复或下次启动时自动补传；
- 失败后按照 15 秒、1 分钟、5 分钟、15 分钟的间隔重试；
- 上传期间产生新修改，会在当前上传完成后再次上传。

开启自动获取云端更新后：

- 启动网站、网络恢复以及页面重新回到前台时检查云端 SHA；
- 本地没有未上传修改且云端版本较新时自动下载；
- 本地和云端都发生变化时停止自动覆盖并显示冲突；
- 一分钟内重复回到前台不会反复请求 GitHub；
- 自动下载不会覆盖当前设备本地保存的 API 密钥和 GitHub Token。

GitHub Contents API 每次上传都会产生一次提交，因此程序不会每次按键都请求 GitHub。

### 多设备与冲突保护

程序会记录上次同步的 GitHub 文件 SHA。自动上传前如果发现云端文件已经被其他设备修改，会停止自动覆盖并显示冲突。

推荐的多设备流程：

1. 在设备 A 学习，等待顶部显示“已保存到云端”。
2. 首次在设备 B 填写同一仓库和 Token；空白设备会自动下载。
3. 以后打开设备 B 或回到页面前台时，程序会自动获取设备 A 的更新。
4. 在设备 B 学习并等待上传完成；回到设备 A 时同样会自动检查更新。

发生冲突时，先导出本地 JSON。以云端为准就下载，以本机为准才手动覆盖；不确定时不要覆盖。

## 云端状态说明

顶部状态始终明确显示当前数据是否已经保存到云端：

| 状态 | 含义 |
| --- | --- |
| ⚪ 未配置云端 | 缺少仓库名或 Token |
| ⚪ 尚未同步到云端 | 已配置，但本机从未成功上传或下载 |
| 🕒 有修改等待上传 | 本地已保存，等待自动上传 |
| 🔄 正在保存到云端 | 正在上传当前数据 |
| 🔄 正在上传，仍有新修改 | 当前上传完成后还会再次上传 |
| 📴 有修改待联网保存 | 当前离线，本地数据安全，联网后补传 |
| ⚠️ 有修改未保存到云端 | 自动云保存已关闭 |
| ❌ 云端保存失败，等待重试 | 上传失败，本地数据仍然保留 |
| ⚠️ 云端冲突，修改尚未保存 | 云端被其他设备修改，自动覆盖已停止 |
| ✅ 已保存到云端 | 没有任何等待上传的修改 |

只有已经成功同步过、没有待上传修改且当前没有上传任务时，程序才会显示“已保存到云端”。点击状态文字可打开云同步详情。

- 设置划词笔记默认词库；

清空排队不会取消已经发出的网络请求；尚未处理的导入任务会标记为失败，之后可以重试。

### 背词设置

可以调整拼错处理、提示、发音、答案内容和复习周期行为。修改后点击“保存设置”。

### 备忘录

用于记录学习计划、词根词缀和易混词。备忘录会跟随词库数据一起本地保存、导出和云同步。

## 常见问题

### 1. 刷新页面后数据不见了

确认是否仍在同一浏览器、同一配置文件和同一页面地址。移动 HTML、清理网站数据或使用无痕窗口可能对应不同的本地存储。尝试从云端下载或导入最近的 JSON 备份。

### 2. AI 接口测试成功，但生成词条失败

导入 API 必须返回可解析的纯 JSON。检查 Prompt 是否保留必需字段，模型是否额外输出解释文字，并在“队列/运行日志”中查看错误。

### 3. 在线查询一直停在处理中

查询 API 必须支持 SSE 流式输出。检查接口地址、模型、网络代理和跨域设置。

### 4. GitHub 返回 401 或 403

通常是 Token 无效、过期或权限不足。重新创建 Fine-grained Token，并确认目标仓库的 **Contents: Read and write** 权限。

### 5. GitHub 返回 404

检查仓库名是否严格为 `用户名/仓库名`、Token 是否能访问该私有仓库，以及文件是否严格命名为小写 `vocab_data.json`。

### 6. 为什么显示“尚未同步”，而不是“已保存到云端”

“已保存到云端”必须有成功上传或下载记录。仅填写仓库和 Token 并不代表数据已经存在于云端。

### 7. 为什么自动上传停止并显示冲突

GitHub 文件的 SHA 与本机上次记录不同，说明云端可能被另一设备更新。程序会停止自动覆盖。先备份本地数据，再决定下载云端还是手动覆盖。

### 8. 为什么导入 `children` 后没有变成 `child`

当前只处理普通名词规则复数 `s/es/ies`。`children`、`men`、`leaves` 等不规则或其他拼写变化不会由本地校验接受。

### 9. 发音没有声音

发音依赖浏览器语音合成功能。检查系统音量、浏览器权限和系统是否安装了对应英语语音。

### 10. 如何安全清理测试数据

先导出 JSON，然后切换到需要清理的词库，使用“清空词库数据”或选择后批量删除。不要在未确认当前词库时执行清空。

## 安全注意事项

- 不要把 API 密钥或 GitHub Token 写进 `index.html`、README、Git 提交或公开截图。
- GitHub Token 使用 Fine-grained PAT，只授权专用私有仓库和 Contents 读写权限。
- 密钥保存在当前浏览器的 `localStorage` 中；不要加载来历不明的修改版网页。
- 导出 JSON、云端数据和另存 HTML 会清理敏感密钥，但分享前仍应自行检查文件内容。
- 云端下载和覆盖上传都可能覆盖数据，重要操作前先导出 JSON。
- Token 过期、泄露或不再使用时，应立即在 GitHub 设置中撤销。
